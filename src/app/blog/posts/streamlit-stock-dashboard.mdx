My [real-time stock analysis dashboard](/work/stock) started as a weekend experiment: could I get TradingView-style charts with indicators using only Python? Streamlit made it surprisingly quick. Here is the core of how it works.

## Step 1: fetch price data

`yfinance` pulls historical OHLCV data from Yahoo Finance. Wrap it in `st.cache_data` with a TTL so repeated interactions don't refetch every time.

```python
import streamlit as st
import yfinance as yf

@st.cache_data(ttl=60)
def load(ticker: str, period: str):
    return yf.Ticker(ticker).history(period=period)

ticker = st.sidebar.text_input("Ticker", "AAPL")
period = st.sidebar.selectbox("Period", ["1mo", "3mo", "6mo", "1y"])
df = load(ticker, period)
```

## Step 2: compute indicators with pandas

```python
df["SMA20"] = df["Close"].rolling(20).mean()
df["EMA20"] = df["Close"].ewm(span=20, adjust=False).mean()

delta = df["Close"].diff()
gain = delta.clip(lower=0).ewm(alpha=1/14, adjust=False).mean()
loss = (-delta.clip(upper=0)).ewm(alpha=1/14, adjust=False).mean()
df["RSI14"] = 100 - 100 / (1 + gain / loss)
```

The `alpha=1/14` exponential smoothing is Wilder's method, which is what most charting platforms use for RSI.

## Step 3: plot with Plotly

```python
import plotly.graph_objects as go

fig = go.Figure([
    go.Candlestick(x=df.index, open=df["Open"], high=df["High"],
                   low=df["Low"], close=df["Close"], name=ticker),
    go.Scatter(x=df.index, y=df["SMA20"], name="SMA 20"),
    go.Scatter(x=df.index, y=df["EMA20"], name="EMA 20"),
])
fig.update_layout(xaxis_rangeslider_visible=False, height=520)
st.plotly_chart(fig, use_container_width=True)

st.line_chart(df["RSI14"])
```

## Step 4: show the headline numbers

```python
last, prev = df["Close"].iloc[-1], df["Close"].iloc[-2]
st.metric(ticker, f"{last:.2f}", f"{(last - prev) / prev:.2%}")
```
